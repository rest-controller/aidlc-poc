## Mandated

- ALWAYS name branches as `AP-<n>-<summary>` (the Jira ticket key plus a short summary) and raise a pull request to `main` before merging.
- ALWAYS work one ticket at a time and ask the person "next is AP-n, should I do it?" before starting a ticket.
- ALWAYS confirm with the person before creating tickets, opening pull requests, replying on GitHub or changing a ticket's status.
- ALWAYS mark a ticket "Done" only when the person approves or merges its pull request.

## Forbidden

- NEVER merge directly to `main` without a pull request.
