# Team Allocation: User Sign-Up

A Bolt is one build pass over a piece of the work, ending in something that runs; the eight Bolts are listed in `bolt-plan.md`. A mob is the group of people or agents that works one Bolt together.

Sources: `bolt-plan.md`, `unit-of-work.md`, `team-practices.md`. Team Formation was skipped in the classic plan, so there are no teams from it to reference.

## Allocation

| Bolt | Jira | Owner |
|---|---|---|
| B1 to B8 | AP-4, AP-5, AP-6, AP-8, AP-9, AP-10, AP-7, AP-3 | The AI developer builds every Bolt, one at a time |

## Roles and decisions that stay with the person

- **AI developer:** writes the code and tests, creates the branch, and prepares the pull request.
- **The person:** says yes before each ticket starts ("next is AP-n, should I do it?"), approves each pull request, and is the only one who closes a ticket. Creating tickets, opening pull requests, replying on GitHub and changing a ticket's status are confirmed with the person first.
- **Review comments:** before the next ticket is offered, all open pull requests are checked for new comments; each comment is treated as change feedback on that ticket's branch and answered fully.

There is a single mob, so there is no program board to coordinate and no hand-offs between teams.
