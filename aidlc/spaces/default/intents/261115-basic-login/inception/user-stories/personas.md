# Personas

## Demo User (primary)

- **Role:** The developer running the POC, or their colleague Pallav, who tries the login in a browser and evaluates AI-DLC's output.
- **Goals:** Sign in with the demo credentials and see the success page; see a clear message when the credentials are wrong; run and test the app on their own machine.
- **Pain points:** Unclear failure feedback; setup that needs more than a local run.
- **Context:** Local machine, browser, no deployment, no real user data.

## Persona Relationships and Priority

One persona. The person using the login and the person running the project are the same two people, so there is nothing to rank.
